# 基本機能・安定性の確認

## 自動テスト

依存なしの追跡テスト：

```powershell
cmake -S . -B build-core -DFPF_CORE_ONLY=ON
cmake --build build-core --config Release
ctest --test-dir build-core -C Release --output-on-failure
```

検証内容：鼻・左右の目・反転座標・顔ローカル補正・傾き・角度の±π境界・平滑化・再初期化・近傍顔選択・一時的な別人の拒否・再選択・空検出。

OpenCV込みでは `detector-test` もビルドされます。Windowsで実行する場合はOBSの `bin/64bit` をPATHへ追加し、libobsの依存DLLを解決してください。任意の顔画像を320×320のraw RGBA（409600バイト）に変換し、次のように実行できます。テスト用人物画像は配布物に含めていません。

```powershell
.\build_x64\bin\RelWithDebInfo\detector-test.exe .\data\models\face_detection_yunet_2023mar.onnx <320x320のraw-RGBAファイル>
```

`-DFPF_TEST_RGBA=<絶対パス>` をCMake設定に追加するとCTestにも登録します。顔の5点推論、黒フレーム、最新キュー、処理中の終了、欠損モデルを確認します。

## Windows OBSの手動テスト（未実施）

各試験のOBSバージョン、GPU/ドライバー、CPU、解像度/FPSを記録します。配信前にローカル録画で確認してください。

| 手順 | 期待結果 |
|---|---|
| DLL・データをインストールしOBS起動 | ログに `version 0.1.0 loaded`。エフェクトフィルタ一覧に日本語名 |
| Webカメラに追加、PNG未選択 | カメラが透過・真っ黒にならずそのまま表示 |
| 透過PNGを選択、鼻を指定 | 背景が透過し鼻へ表示。録画にも同じ合成結果 |
| 顔を上下左右・近く遠く・傾ける | 位置・サイズ・ロールが追従。角度補正が急に一周しない |
| 左右の目・中心・口・額・頬・顎・カスタムに切替 | 指定位置へ移動。額・頬・顎は推定の限界を確認 |
| 基準点・拡大率・不透明度・X/Y補正・回転補正 | 即時反映。半透明縁に黒/白のハローが出ない |
| 自動拡縮/回転をOFF | 固定100px×拡大率の幅、固定補正角度になる |
| 静止・素早い移動、平滑化0/0.35/1 | 平滑化が強いほど揺れを抑え遅延が増える |
| 一瞬顔を隠す→保持時間以上隠す→再登場 | 短い失敗は保持、超過で非表示、再検出で自然に移動 |
| 非表示設定をOFF | 一度検出した後の最後の位置に残る |
| 別人が一瞬入る・2人が交差 | 元の近傍を優先。本人識別がない限界も記録 |
| PNG変更・同パスを編集して再読込 | OBS再起動なしで更新 |
| PNG破損・消去後の再読込・未選択 | 警告ログ、元映像の継続、クラッシュなし |
| モデル削除・破損でフィルター新規追加 | エラーログと赤い状態バー。カメラ映像継続 |
| カメラ切断・再接続、720p→1080p | 黒画面や異常位置が継続せず、寸法変更後に再追従 |
| 前後段クロップ/反転、シーン反転 | 元映像とマーカーの一致、二重反転しない |
| 同じソースを複数シーンで表示 | 描画回数で平滑化速度が変わらない |
| 有効/無効・シーン切替・再起動 | 表示と保存設定が正しい |
| 連続追加/削除100回、推論中に削除/OBS終了 | ハング、クラッシュ、メモリ/GPUリソース増加なし |
| 720p30を10分、60fpsを10分録画 | OBS統計の描画遅延/エンコード遅延とCPU/GPU使用率を記録 |
| HDRソース | 元映像通過、PNGは表示しない（SDR限定仕様） |

状態バー：緑=有効な顔、黄=保持、灰=未検出、赤=モデル/推論エラー。デバッグ表示も配信・録画に入るため確認後OFFにしてください。
